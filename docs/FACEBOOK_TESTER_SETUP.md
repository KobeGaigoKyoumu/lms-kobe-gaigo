# Facebook Messenger 連携（テスト運用）手順

Facebookアプリの審査を行わず、特定のユーザー（学生）のみが連携機能を利用できるようにする「テスト運用」の手順です。
この方法では、学生のFacebookアカウントをアプリの「テスター」として登録する必要があります。

## 手順概要

1.  **管理者:** Facebook Developers コンソールで学生を「テスター」として招待する。
2.  **学生:** Facebook上で「招待」を承認する。
3.  **学生:** LMSアプリから連携を行う。

---

## 1. 管理者側の作業（テスターの招待）

1.  [Meta for Developers](https://developers.facebook.com/) にアクセスし、管理しているアプリを選択します。
2.  左メニューの **「アプリの役割 (App Roles) > 役割 (Roles)」** をクリックします。
3.  「**テスター (Testers)**」セクションにある「**テスターを追加 (Add Testers)**」ボタンをクリックします。
4.  学生の **Facebookユーザー名** または **Facebook ID (fbid)** を入力して検索・選択します。
    *   ※学生とFacebook上で友達になっていると検索しやすいです。
5.  「**送信 (Submit)**」をクリックします。

これで学生のアカウントに招待が送信されます。ステータスは「保留中 (Pending)」となります。

> [!WARNING]
> **テスターの人数の上限について**
> 通常、登録できるテスターの人数は **50名まで** です。
> ※ビジネス認証（Business Verification）を完了したビジネスアカウントに紐付いている場合のみ、最大500名まで拡張可能です。
> 50名を超える学生全員に利用させる場合は、原則として「ライブモード（アプリレビュー通過）」への切り替えが必要になります。

## 2. 学生側の作業（招待の承認）

**重要:** 管理者が招待しただけでは完了しません。学生自身が招待を承認する必要があります。

以下のいずれかの方法で承認を行ってもらってください。

### 方法A: 通知から承認する
1.  Facebookアプリ（またはWeb版）の「お知らせ（ベルマーク）」を開く。
2.  「[管理者名]から[アプリ名]のテスターとしてのリクエストが届いています」という通知をタップする。
3.  「承認する (Confirm)」ボタンを押す。

### 方法B: 開発者ページから承認する（通知が来ない場合）
1.  学生のスマートフォンやPCでブラウザを開き、以下のURLにアクセスする（Facebookへのログインが必要）。
    *   URL: [https://developers.facebook.com/settings/developer/requests/](https://developers.facebook.com/settings/developer/requests/)
2.  「保留中のリクエスト」に表示されているアプリの「承認する (Confirm)」ボタンを押す。
    *   ※初めてアクセスする場合、「Facebook開発者として登録」の画面が出ることがありますが、その場合は登録を進めてください（電話番号認証などが求められる場合があります）。

## 3. 連携の確認

招待が承認されれば、その学生のアカウントは「開発者モード」のアプリにアクセスできるようになります。

1.  LMSアプリにログインする。
2.  Messenger連携ボタンを押す。
3.  Messengerが開き、「スタート」ボタンが表示されることを確認する。
4.  「スタート」を押して、自動返信メッセージが届けば成功です。
