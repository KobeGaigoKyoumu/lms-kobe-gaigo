# Facebook Messenger 連携（App Review）申請手順

学生（一般ユーザー）がMessenger連携機能を利用するには、Facebookアプリを「ライブモード」にする必要があります。そのためには、Meta社の「**アプリレビュー（App Review）**」に合格し、`pages_messaging` 権限を取得する必要があります。

以下に、申請（上記手順「2」）の具体的なステップを示します。

## 事前準備

申請には以下の情報・素材が必須です。事前に準備してください。

1.  **プライバシーポリシーのURL**
    *   アプリ（LMS）内にプライバシーポリシーのページが必要です（例: `/privacy`）。
    *   Facebook Developersコンソールの「設定 (Settings) > 基本 (Basic)」にこのURLを入力して保存してください。
2.  **デモ動画（Screencast）**
    *   アプリがどのようにMessengerを使用するかを示す動画ファイル。
    *   **重要:** 審査官が確認できるよう、**現在動作しているアカウント（テスターに追加したアカウント）**を使って録画してください。
    *   **録画内容:**
        1.  LMSにログインする。
        2.  設定画面等の「Messenger連携」ボタンをクリックする。
        3.  Messengerが開き、「スタート」ボタンを押す。
        4.  「連携が完了しました」というメッセージが届くところまで。

## 申請手順

### 1. 権限のリクエスト

1.  [Meta for Developers](https://developers.facebook.com/) にアクセスし、対象のアプリを選択します。
2.  左メニューの **「アプリレビュー (App Review) > リクエスト (Requests)」** をクリックします。
3.  「**アクセス許可と機能をリクエスト (Request Permissions and Features)**」ボタンをクリックします。
4.  検索バーで `pages_messaging` を検索します。
5.  `pages_messaging` の横にある「**リクエスト (Request)**」ボタンをクリックし、「続行 (Continue)」を押します。

### 2. リクエスト詳細の入力

リクエストリストに追加された `pages_messaging` の右側にある「**詳細を表示 (Complete Verification)**」または「編集」をクリックし、以下の情報を入力します。

*   **利用目的の説明:**
    *   英語での記入が推奨されますが、日本語でも可（審査が遅れる可能性あり）。
    *   *文例 (English):* "Our school LMS uses this permission to send important academic notifications (e.g., class cancellations, emergency alerts) to enrolled students who have explicitly opted in via our web portal. The bot replies with a confirmation upon linking."
    *   *文例 (日本語):* "当校のLMS（学習管理システム）において、連携を希望した在籍学生に対して、休講情報や緊急連絡などの重要なお知らせを配信するために使用します。"
*   **デモ動画のアップロード:**
    *   事前準備で作成した動画ファイルをアップロードします。

### 3. ビジネス認証（必須）

`pages_messaging` 権限を利用してアプリをライブモードにする場合、**ビジネス認証 (Business Verification) は必須**です。

1.  **「設定 > ビジネス認証」** に進みます。
2.  「認証を開始」をクリックし、学校法人としての書類（登記簿謄本、公共料金の請求書など）をアップロードします。
3.  ビジネスの住所、電話番号、ウェブサイト（HTTPS）が書類と一致している必要があります。

※この認証が完了しないと、アプリレビューに合格してもライブモードに切り替えることができません。

### 4. 提出と審査

1.  必要な情報の入力がすべて「完了 (Complete)」になったら、画面下部の「**審査に提出 (Submit for Review)**」をクリックします。
2.  審査には通常 **1日～5日程度** かかります。
3.  結果はメールおよびDevelopersコンソールで通知されます。

### 5. ライブモードへの切り替え

1.  審査に合格し、ビジネス認証も完了したら、画面上部の「**アプリモード (App Mode)**」トグルスイッチを **「開発 (Development)」から「ライブ (Live)」** に切り替えます。
2.  これで、テスター以外の全学生が連携機能を利用できるようになります。

---

### 注意点

*   **審査中の対応:** 審査官から追加の質問や、テスト用アカウント（LMSのログインID/PW）の提供を求められることがあります。メッセージセンターをこまめに確認してください。
*   **却下された場合:** 理由は具体的に示されます（例：「動画で機能が確認できなかった」など）。修正して再提出すれば問題ありません。
